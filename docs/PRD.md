## 一、项目背景与目标

### 1.1 背景
逛展时用户最常遇到两个问题：
- **走马观花**：缺乏节奏感，看完记不住。
- **体力透支**：长时间连续观展，注意力下降、身体疲劳。

番茄工作法「25 分钟专注 + 5 分钟休息」的节奏恰好匹配展厅里的注意力曲线，帮助用户有节奏地观展。

### 1.2 产品目标
- 提供一个**极简、即时可用**的计时工具。
- 用**视觉色彩**而非文字传达当前状态（专注 or 休息）。
- 确保在**嘈杂展厅环境**下到点提醒不被遗漏。

### 1.3 成功指标
- 单文件可双击运行，无需任何环境配置。
- 移动端浏览器打开即可使用，触摸响应流畅。
- 用户一眼（不读字）就能判断当前处于专注还是休息阶段。

## 四、交互需求

### 4.1 启动
- 打开页面后显示门票，中央显示倒计时初始时间 `25:00`。
- 底部/中央有一个醒目的「开始」按钮。
- 点击开始后按钮变为「暂停」，计时启动。

### 4.2 阶段切换
- 专注结束 → 自动切换到休息（5:00），整屏颜色翻转为休息主题。
- 休息结束 → 自动切换回专注（25:00），整屏颜色翻转为专注主题。
- 每次切换均触发全屏闪烁 + 提示音。

### 4.3 状态识别
- 用户**无需读字**，仅凭整屏背景颜色即可判断：
  - 专注主题色 → 该看展了
  - 休息主题色 → 该歇会儿了

## 五、视觉设计规范

### 5.1 配色方案（多巴胺撞色风）

**专注阶段（Focus）：**
| 元素 | 颜色 | 说明 |
|------|------|------|
| 背景主色 | 荧光绿（如 `#39FF14`） | 高饱和，传递活力与专注 |
| 背景辅色 | 亮紫（如 `#8B5CF6`） | 撞色对比 |
| 背景第三色 | 亮橙（如 `#FF6B35`） | 多色拼接多巴胺风 |
| 票面底色 | 白色 / 米白 | 门票质感 |
| 数字填充 | 背景辅色 `#8B5CF6` | 与白底形成强对比 |
| 数字描边 | 纯黑 `#000000`，4px | 粗黑描边，强视觉冲击 |

**休息阶段（Break）：**
| 元素 | 颜色 | 说明 |
|------|------|------|
| 背景主色 | 热粉（如 `#FF2D95`） | 放松、休闲 |
| 背景辅色 | 亮黄（如 `#FFE600`） | 撞色对比 |
| 背景第三色 | 亮青（如 `#00E5FF`） | 多色拼接多巴胺风 |
| 票面底色 | 白色 / 米白 | 门票质感 |
| 数字填充 | 背景辅色 `#FFE600` | 与白底形成强对比 |
| 数字描边 | 纯黑 `#000000`，4px | 粗黑描边 |

> 具体色值可在实现阶段微调，原则是**高饱和、强对比、不刺眼**。
> **背景采用多色拼接色块**（主色+辅色+第三色），避免长时间单色对视觉造成疲劳。

### 5.2 门票结构
- **外层**：白色票面 + 粗黑描边（`border: 4px solid #000`）+ 投影。
- **中线**：水平虚线（`border-style: dashed`）模拟撕票线，两侧带圆形打孔。
- **数字**：超大字号，填充色为 `var(--bg-secondary)`，4px 黑描边，居中。
- **票头**：阶段标识（FOCUS / BREAK）+ 副标题（EXHIBITION PASS）。
- **票根**：控制按钮 + 「今日已完成 N 段」计数。
- **四角**：半圆缺口模拟票根打孔。

### 5.3 字体
- 倒计时数字：粗体无衬线字体（如 `Arial Black` / `system-ui` 加粗）。
- 字号：`clamp(64px, 22vw, 116px)` 自适应（不超出票面宽度 372px）。
- 描边：`-webkit-text-stroke: 4px #000`，填充色 `var(--bg-secondary)`。

## 六、非功能需求

| 编号 | 需求 |
|------|------|
| NF-01 | **零依赖**：不引入任何外部 CSS/JS 库、框架、字体、音频文件。 |
| NF-02 | **单文件**：所有 HTML/CSS/JS 内联在一个 `index.html` 中。 |
| NF-03 | **双击运行**：双击文件即可在浏览器中打开使用，无需本地服务器。 |
| NF-04 | **移动端优先**：在手机浏览器中显示正常、触摸响应流畅。 |
| NF-05 | **现代浏览器兼容**：Chrome / Safari / Edge 最新两个版本。 |
| NF-06 | **实现成本**：开发时间控制在 80 分钟以内。 |
| NF-07 | **无网络依赖**：离线可用。 |

## 七、验收标准

1. ✅ 双击 `index.html` 能直接在浏览器打开，无报错。
2. ✅ 点击「开始」后数字从 `25:00` 逐秒递减。
3. ✅ 倒计时到 `00:00` 时整屏闪烁 + 播放提示音，并自动切换到休息阶段。
4. ✅ 阶段切换时整屏背景颜色突变翻转。
5. ✅ 休息阶段倒计时到 `00:00` 后自动切回专注，循环往复。
6. ✅ 手机端打开页面，门票完整显示，按钮可点击，无横向滚动。
7. ✅ 无任何外部资源请求（网络面板为空）。
