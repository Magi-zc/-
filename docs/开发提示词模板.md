# 展票番茄钟 · 全流程开发提示词模板

> 本提示词用于指导 AI Agent 按阶段完成「展票番茄钟」的开发。
> **核心铁律**：每完成一个阶段，必须先将操作记录写入 `进度笔记.md`，再与三份交付文档交叉核对，确认无偏离后才进入下一阶段。

---

## 📋 交付文档清单（开发全程必须对照）

| 文档 | 路径 | 作用 |
|------|------|------|
| 产品需求文档 | `docs/PRD.md` | 功能点 F-01~F-15、非功能 NF-01~NF-07、验收标准 |
| 技术需求文档 | `docs/技术需求文档.md` | 技术选型、模块设计、兼容性、风险应对 |
| 架构设计 | `docs/架构设计.md` | 技术架构图、功能架构图、`index.html` 骨架 |

---

## 🚀 使用方式

将以下**完整提示词**发送给 Agent，Agent 将按阶段推进开发。每个阶段结束后，Agent 会自动：
1. 更新 `进度笔记.md`
2. 与三份交付文档核对
3. 汇报本阶段完成情况，等待确认后进入下一阶段

═══════════════════════════════════════════════

3. 核对通过后，输出：「阶段N 完成，已核对文档，无偏离」

【阶段 1：CSS 主题系统 + 基础布局】
═══════════════════════════════════════════════
目标：建立双套撞色主题变量和页面基础布局。

任务：
1. 读取 docs/架构设计.md §3.2 的 index.html 骨架。
2. 在 <style> 中实现 CSS 变量主题系统（技术文档 §3.1）：
   - :root 定义专注主题：--bg-primary:#39FF14, --bg-secondary:#8B5CF6, --ticket-bg:#FFFFFF, --ink:#000000
   - body[data-phase="break"] 覆盖为休息主题：--bg-primary:#FF2D95, --bg-secondary:#FFE600
3. 实现全局重置 + body 背景使用 --bg-primary，高度 100dvh（技术文档 §四）。
4. body 默认 data-phase="focus"。

核对依据：
- PRD F-14（双套撞色主题）、PRD §5.1（配色方案）
- 技术文档 §3.1（主题配色系统）、§四（移动端视口）
- 架构设计 §3.2 骨架

═══════════════════════════════════════════════
【阶段 2：门票视觉】
═══════════════════════════════════════════════
目标：实现门票拟物外观。

任务：
1. 在 <body> 内构建门票 DOM（参考架构设计 §3.2）：
   <main class="ticket">
     <header class="ticket__header"><span class="ticket__phase">FOCUS</span></header>
     <div class="ticket__countdown" id="countdown">25:00</div>
     <div class="ticket__divider"></div>
     <footer class="ticket__controls">
       <button id="startBtn" class="btn btn--primary">开始</button>
       <button id="resetBtn" class="btn btn--ghost">重置</button>
     </footer>
   </main>
2. 实现门票样式（技术文档 §3.2）：
   - .ticket：白色背景 + border:4px solid #000 + border-radius + box-shadow
   - .ticket__divider：border-top:2px dashed #000（撕票虚线）
   - .ticket__countdown：font-size:clamp(80px,30vw,200px) + font-weight:900 + -webkit-text-stroke 粗黑描边
3. 居中布局，门票占满主要可视区域。

核对依据：
- PRD F-10（门票拟物）、F-11（超大数字）、F-12（粗黑描边）、F-13（撕票虚线）
- PRD §5.2（门票结构）、§5.3（字体）
- 技术文档 §3.2（门票视觉）

═══════════════════════════════════════════════
【阶段 3：计时引擎】
═══════════════════════════════════════════════
目标：实现 25+5 循环倒计时逻辑。

任务：
1. 在 <script> 中定义状态变量：phase('focus'|'break'), remaining(秒), isRunning, timerId
2. 定义常量：FOCUS_DURATION=25*60, BREAK_DURATION=5*60
3. 实现函数：
   - formatTime(s): 转 MM:SS，不足两位补零
   - renderCountdown(): 更新 #countdown 文本
   - startTimer(): setInterval(fn,1000)，每秒 remaining--，到 0 时调用 switchPhase()
   - pauseTimer(): clearInterval
   - resetTimer(): 回到 IDLE，remaining=FOCUS_DURATION，显示 25:00
   - switchPhase(): phase 切换 focus↔break，重置 remaining 为对应时长，重新计时
4. 绑定 startBtn 事件：isRunning 为 false 时 startTimer，为 true 时 pauseTimer；按钮文案在「开始」「暂停」间切换
5. 绑定 resetBtn 事件：resetTimer

核对依据：
- PRD F-01（25+5循环）、F-02（每秒倒计时）、F-03（自动切换）、F-04（开始）、F-05（暂停/继续）、F-06（重置）
- PRD §4.1（启动交互）、§4.2（阶段切换）
- 技术文档 §3.3（计时逻辑 + 状态机）

═══════════════════════════════════════════════
【阶段 4：全屏闪烁提醒】
═══════════════════════════════════════════════
目标：到点时全屏闪烁。

任务：
1. 在 <style> 中定义 @keyframes flash：背景在 var(--bg-primary) 与 #fff/#000 之间快速交替
2. 定义 body.flashing 应用该动画，持续 2-3 秒
3. 在 switchPhase() 中调用 triggerFlash()：给 body 添加 .flashing，动画结束后移除
4. 色块翻转：body 背景加 transition: background-color 0.3s（技术文档 §3.5）

核对依据：
- PRD F-07（全屏闪烁）、F-15（色块翻转）
- 技术文档 §3.4.1（视觉闪烁）、§3.5（色块翻转）

═══════════════════════════════════════════════
【阶段 5：蜂鸣提示音】
═══════════════════════════════════════════════
目标：到点时播放醒目提示音。

任务：
1. 实现音频模块（技术文档 §3.4.2）：
   - initAudio(): 创建 AudioContext，**必须在用户首次点击 startBtn 时调用**（⚠️ 自动播放策略）
   - playBeep(): 创建 OscillatorNode，频率 880Hz，波形 square，时长 0.3s，连续响 2-3 次间隔 0.2s
2. 在 startBtn 点击事件中先调用 initAudio()/resume()
3. 在 switchPhase() 中调用 playBeep()

⚠️ 关键约束：AudioContext 必须在用户交互事件中初始化，否则被浏览器拦截。

核对依据：
- PRD F-08（播放提示音）、F-09（嘈杂环境可感知）
- 技术文档 §3.4.2（听觉提示 + 注意事项）
- 技术文档 §八 风险表（iOS Safari 自动播放策略）

═══════════════════════════════════════════════
【阶段 6：移动端适配 + 整体验收】
═══════════════════════════════════════════════
目标：确保移动端可用，通过全部验收标准。

任务：
1. 确认 viewport meta 已设置（技术文档 §四）：
   width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no
2. 按钮监听 touchstart 事件（消除 300ms 延迟），同时保留 click 兼容
3. 检查 100dvh 视口高度适配
4. 对照 PRD §七 验收标准逐条自测：
   ✅ 双击 src/index.html 能打开，无报错
   ✅ 点击开始后 25:00 逐秒递减
   ✅ 到 00:00 时全屏闪烁 + 提示音，自动切休息
   ✅ 阶段切换整屏颜色翻转
   ✅ 休息到 00:00 自动切回专注，循环
   ✅ 手机端门票完整显示，按钮可点，无横向滚动
   ✅ 无任何外部资源请求
5. 确认零依赖（package.json dependencies 为空，无 CDN/外链）

核对依据：
- PRD §七（验收标准）、NF-01~NF-07（非功能需求）
- 技术文档 §四（移动端适配）、§五（兼容性）、§七（安全隐私）

═══════════════════════════════════════════════
【全局约束（贯穿所有阶段）】
═══════════════════════════════════════════════
- 单文件：所有 HTML/CSS/JS 内联在 src/index.html 中（NF-02）
- 零依赖：不引入任何外部库、框架、字体、音频文件（NF-01）
- 不修改 docs/ 下的任何交付文档
- 开发文件只在 src/index.html 中编辑
- 每个阶段结束必须执行【阶段收尾流程】
