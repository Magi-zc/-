## 一、技术选型

### 1.1 选型结论

| 层级 | 选型 | 说明 |
|------|------|------|
| 结构 | 原生 HTML5 | 语义化标签，单文件内联 |
| 样式 | 原生 CSS3（CSS 变量） | 用 `:root` + `[data-phase]` 管理双主题 |
| 行为 | 原生 JavaScript（ES6+） | 无框架，直接操作 DOM |
| 提示音 | Web Audio API | 零依赖合成蜂鸣声 |
| 动画 | CSS `@keyframes` | 全屏闪烁、色块翻转 |
| 构建 | 无 | 不使用任何打包工具 |

### 1.2 选型理由
- **零依赖硬约束**：产品要求单文件双击运行，任何框架/库都会引入外部资源，违反约束。
- **现代浏览器原生能力已足够**：CSS 变量、Web Audio API、`clamp()`、`100dvh` 等特性在目标浏览器中均已稳定支持。
- **开发效率最高**：跳过环境搭建、依赖安装、构建配置，直接写代码。

## 三、核心模块设计

### 3.1 主题配色系统（CSS 变量）

**实现思路**：
- 在 `:root` 定义默认（专注）主题变量。
- 用 `body[data-phase="break"]` 覆盖变量实现休息主题。
- 所有使用颜色的地方引用变量，切换阶段只需改 `data-phase` 属性。

**关键变量**：
| 变量名 | 专注值 | 休息值 | 用途 |
|--------|--------|--------|------|
| `--bg-primary` | 荧光绿 `#39FF14` | 热粉 `#FF2D95` | 全屏背景主色 |
| `--bg-secondary` | 亮紫 `#8B5CF6` | 亮黄 `#FFE600` | 背景辅色 / 数字填充 |
| `--bg-tertiary` | 亮橙 `#FF6B35` | 亮青 `#00E5FF` | 背景第三色（多色拼接） |
| `--ticket-bg` | #FFFFFF | #FFFFFF | 票面底色 |
| `--ink` | #000000 | #000000 | 描边 / 文字 |

**背景实现**：使用 `linear-gradient` 将主色、辅色、第三色拼接成多色块多巴胺背景，避免长时间单色视觉疲劳。

### 3.2 门票视觉（CSS）

| 元素 | 实现方式 |
|------|----------|
| 票面 | 白色块 + `border: 4px solid #000` + `border-radius` + `box-shadow` |
| 撕票虚线 | 票面中部 `border-top: 2px dashed #000` + 两侧圆形打孔伪元素 |
| 超大数字 | `font-size: clamp(64px, 22vw, 116px)` + `font-weight: 900` + `color: var(--bg-secondary)` + `-webkit-text-stroke: 4px #000` |
| 计数器 | 票根处展示「今日已完成 N 段」，每完成一个阶段 +1 |
| 四角缺口 | 伪元素 `::before` / `::after` 画圆形遮罩 |

### 3.3 计时逻辑（JS）

**状态机**：
```
IDLE → FOCUS(25:00) → BREAK(5:00) → FOCUS(25:00) → ...
         ↑                              |
         └──────── 到点自动切换 ─────────┘
```

**关键实现**：
- 用 `setInterval(fn, 1000)` 每秒递减剩余秒数。
- 剩余时间 = 0 时：触发提醒 → 切换阶段 → 重置倒计时。
- 暂停时 `clearInterval`，继续时重新 `setInterval`。

**时间格式化**：
- `MM:SS` 格式，不足两位补零。

### 3.4 到点提醒

#### 3.4.1 视觉闪烁（CSS）
- 定义 `@keyframes flash`：背景在主题色与白/黑之间快速交替。
- 到点时给 `body` 添加 `.flashing` class，动画结束后移除。
- 闪烁持续约 2-3 秒。

#### 3.4.2 听觉提示（Web Audio API）
- 使用 `AudioContext` + `OscillatorNode` 合成蜂鸣声。
- 参数：频率 `880Hz`（A5），波形 `square`（方波更刺耳、穿透力强），时长 `0.3s`。
- 连续响 2-3 次，间隔 `0.2s`。

**⚠️ 关键注意**：
- `AudioContext` 必须在用户首次交互（点击开始按钮）时创建或 `resume()`，否则被浏览器自动播放策略拦截。
- 在 `start` 按钮的点击/触摸事件中初始化音频上下文。

### 3.5 色块翻转（CSS 过渡）
- `body` 背景使用 CSS 变量。
- 切换 `data-phase` 时，背景色通过 `transition: background-color 0.3s` 平滑过渡（或瞬时翻转，按产品需求"色块翻转"建议瞬时或极短过渡）。

## 四、移动端适配与无障碍

| 需求 | 实现方式 |
|------|----------|
| viewport | `<meta name="viewport" content="width=device-width, initial-scale=1">`（**移除 `user-scalable=no` 与 `maximum-scale=1`**，允许用户缩放，符合无障碍规范 NF-08） |
| 视口高度 | 使用 `100dvh`（动态视口高度），避免地址栏挤压 |
| 触摸响应 | 主按钮监听 `touchstart` 事件，消除 300ms 点击延迟 |
| 字号自适应 | `clamp()` 函数，大屏大、小屏小 |
| 安全区 | 可选 `padding: env(safe-area-inset-*)` 适配刘海屏 |
| 无障碍标签 | 所有按钮添加 `aria-label`，倒计时区域添加 `aria-live="polite"` |

## 五、浏览器兼容性要求

| 特性 | 最低浏览器版本 |
|------|----------------|
| CSS 自定义属性（变量） | Chrome 49+ / Safari 9.1+ / Edge 16+ |
| `clamp()` | Chrome 79+ / Safari 13.1+ / Edge 79+ |
| `100dvh` | Chrome 108+ / Safari 15.4+ / Edge 108+ |
| Web Audio API | Chrome 35+ / Safari 14.1+ / Edge 12+ |
| `setInterval` / `clearInterval` | 全版本支持 |

> 目标浏览器均为「最新两个版本」，以上特性全部满足，无需 polyfill。

## 七、安全与隐私

- 不收集任何用户数据。
- 不发起任何网络请求。
- 不使用 `localStorage` / `cookies` / 第三方服务。
- 音频仅在用户主动交互后播放，符合浏览器自动播放策略。

## 八、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| iOS Safari 自动播放策略拦截音频 | 到点无声音 | 在「开始」按钮交互中 `resume()` AudioContext |
| 移动端 `100vh` 被地址栏挤压 | 门票显示不全 | 使用 `100dvh` 动态视口单位 |
| 设备静音模式下提示音不响 | 提醒遗漏 | 全屏闪烁作为兜底视觉提醒 |
| `setInterval` 在后台被节流 | 计时不准 | 用时间戳差值校准（可选增强，本项目秒级可接受） |
| Web Audio 在部分浏览器需前缀 | 兼容性 | 统一用标准 `AudioContext`，目标浏览器均支持 |
